# ⚖️ Hukm (حُكم) - Islamic Jurisprudence & Prophetic Hadiths Encyclopedia

A comprehensive, modern web-based Islamic encyclopedia designed as a school project to provide easy access to authenticated fatwas (rulings) and prophetic hadiths with grade verification and meanings.

## 🚀 Features

- **1,000 Fiqhi Rulings (Fatwas):** Covered across major Islamic jurisprudence categories (Worship, Financial Transactions, Family, etc.).
- **1,000 Prophetic Hadiths:** Includes authentic, hassan, and categorized weak/fabricated hadiths for educational awareness, complete with detailed meanings and explanations.
- **Instant Search:** Fast search functionality across all rulings and hadiths.
- **Dark/Light Mode:** Seamless theme switching for comfortable reading.
- **Bookmarks & Copy:** Save favorite rulings and easily copy any fatwa or hadith with a single click.
- **Responsive Design:** Fully optimized for mobile phones, tablets, and desktop screens.

## 🛠️ Built With

- **HTML5 & CSS3**
- **Tailwind CSS** (via CDN for rapid modern styling)
- **JavaScript (ES6+)**
- **Lucide Icons**
